## Nano Template

一个**实验性**的项目, 用于个人在 ai 时代下做一些关于个人开发效率提升的实验. 如果你对这个项目感兴趣, 直接 clone 即可.

### 如何使用?

```bash
git clone --depth=1 git@github.com:wensboy/nano_template.git
cd nano_template
# 完善必要的配置后
docker compose up -d
```

**tips: 由于项目完全符合一个标准的全栈项目, 比较直观, 因此遇到实际问题完全可以借助 ai 工具来轻松使用项目.**
